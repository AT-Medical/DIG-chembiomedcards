# Project Overview

ChemBioMed Cards ist als einheitliches Referenzsystem für Lernkarten in Chemie, Biochemie, Molekularbiologie, Ernährung, Medizin und perspektivisch Pharmakologie konzipiert.

Kernprinzip: Eine Karte wird als strukturierter Datensatz verwaltet und in Print- sowie Online-Ausgabeformen überführt.
