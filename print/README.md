# Print-Achse

Diese Struktur enthält die druckbezogenen Bestandteile der ChemBioMed Cards.

- `templates/`: Layout-/Satzvorlagen für DIN-A6-Querformat
- `packages/`: modulare Kartenpakete für spätere Produktion/Vertrieb
- `assets/`: front/back-Assets, QR-Grafiken, Logos

Hinweis: Produktionsdateien werden erst mit finalem Designprozess ergänzt.
