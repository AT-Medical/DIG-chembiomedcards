# Onlineplattform-Achse

Framework-neutrale Grundstruktur für die Online-Lernkartenbox.

- `frontend/`: Tablet-first UI, Kartenansicht, Filter, Lernstatus, Notizen
- `backend/`: API, Karten-/Status-/Notizlogik, Paketfreischaltungen
- `auth/`: Vorbereitung für Gateway/SSO-Anbindung
- `integrations/`: WordPress/WooCommerce, LMS, Redirect-Service
- `storage/`: Konventionen für Medien- und Nutzerdateien
