# Datenbasis

Diese Struktur bildet Karten als Datensätze ab (statt nur als Bilddateien).

- `cards/`: YAML/JSON-Beispieldatensätze
- `imports/`: CSV-Importvorlagen
- `exports/`: Platzhalter für Print/Web/PDF/Anki-Exporte
- `redirects/`: QR-Shortlink-Mappings
- `packages/`: Paket- und Lizenzzuordnung
- `schemas/`: Datenmodelle/Validierungsschemata
