# Inward Tabs System

- Tabs starten am oberen Kartenrand und laufen **nach innen** in die Karte
- Tabs stehen **nicht** über den Kartenrand hinaus
- Keine zusätzliche Stanz-/Bruchproblematik in der Druckproduktion
- Der Registereffekt bleibt durch einen farbigen oberen Kartenrand sichtbar
- Tab-System unterstützt Gruppierung nach:
  - Level
  - Bereich (AC/OC/BC/MB/APC/PH)
  - Thema
  - Kartentyp
