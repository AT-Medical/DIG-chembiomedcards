# User Notes

Nutzer können pro Karte eigene Notizen speichern.

## Anforderungen
- Notizen erscheinen standardmäßig unter der Karte
- optional kann eine Einblendung auf der Karte selbst unterstützt werden
- Notizen sind privat pro Nutzer
- Notizen werden persistent gespeichert
- Exportfähigkeit wird für spätere Ausbaustufen vorbereitet
