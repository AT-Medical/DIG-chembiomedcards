# Custom Card Sets

Nutzer können eigene Kartenpakete und individuelle Lerngruppen erstellen.

## Funktionsumfang
- Karten während des Durcharbeitens markieren
- persönliche Wiederholungssets zusammenstellen
- Favoritenlisten aufbauen
- schwierige Karten separat sammeln

## Weiterentwicklung
- Export- und Filterfunktionen werden strukturell vorbereitet
